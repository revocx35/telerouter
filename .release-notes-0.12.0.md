A tmux page: every session on your machines, as a terminal in the browser (v0.12.0)

The tmux sessions page lists every tmux session on every machine telerouter can reach - including
the agents' own sessions - and says what runs in each one (Claude Code, Hermes, Codex, a shell), how
many windows, its folder, its size and when it was last active. Open one and it becomes a terminal in
the browser: you read the pane and type into it.

## No VNC, no screen streaming

The screen is read as text (`tmux capture-pane`) and drawn by the browser, which parses the colour
escapes itself; what you type is pasted into the pane (`tmux paste-buffer`, `send-keys` for single
keys). Nothing is encoded as video frames, there is no websocket and no extra port. That means it is
sharp at any zoom and on a phone, a still pane costs no traffic at all, and the text can be selected
and copied like any other page.

Enter sends what you typed, Shift+Enter keeps a line (a multi-line message arrives as one), and the
key row sends Esc, Tab, arrows and Ctrl-C/D/U/Z/L - enough for prompts, menus and stopping a command.
Scrollback shows the last 300 lines above the visible screen.

## Start and close sessions

New session starts one on a machine in a folder you name: the machine's agent (with its configured
model and permission mode), Claude Code, Hermes, or a plain shell. Claude Code's start-up dialog is
answered for you while you watch it happen. Kill closes a session, except the session of one of
telerouter's own agents - that one belongs to the Agents & machines page and would be restarted at
once.

## Also

- Agents & machines: each agent card has an "Open in tmux" link to the same terminal.
- The page polls only what changed: a screen carries a hash, and an unchanged pane answers "same"
  with no payload.
- Which agent runs in a session is read from the pane's processes, so a pane that looks like `sh` (a
  Hermes launcher, say) still shows the agent that is really in it; telerouter's own agents are
  labelled from their configuration first.
- Docs: README section, ARCHITECTURE 4.3, AGENTS.md hard-won facts.
